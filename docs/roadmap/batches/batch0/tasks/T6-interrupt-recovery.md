# T6 — 中断恢复（standard 档）

- **起始状态**：T3 执行到「execute 阶段关门检查前」的中间态快照
  （实现已落盘、ledger 已记录、`gate close` 尚未运行时 kill 进程）。
- **需求原文**：从中断状态恢复并完成 T3 的交付：不重跑已通过的验证、
  不产生重复副作用（事件、ledger、收据各只有一份增量）、最终状态一致。
- **验收条件（对实现者可见）**：
  1. 恢复路径复用幂等续跑语义（`PHASE_CLOSE_RESUMED` 或等价机制）；
  2. events.ndjson 无重复 `phase.end`；ledger 无重复记录；
  3. T3 的验收条件全部满足。
- **禁止事项**：不手工编辑状态文件伪造终态；不删除状态重来。
- **超时预算**：90 分钟墙钟（含恢复）。
- **独立验收保留项**：评估侧 diff 中断点前后的事件流，验证无断言外的重放。
- **风险档位**：standard。
- **备注**：本任务测量 §10.2 故障演练清单的第一项「执行中被打断」；
  其余演练项（重复完成请求、证据对应旧代码等）在批次 3 展开。

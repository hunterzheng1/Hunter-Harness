## 4. 主要成本定位结论（§7 第 4 项）

1. **首跑成本 = 契约学习成本，是当前最大头的流程维护开销**。T1 首跑 49.6 min 中
   ~42 min（85%）是 Harness 自身引入的：隐式字段契约排障（F1-F4、F11、F12）+
   首次仪式写作。这些成本与任务本质复杂度无关——原生组同任务零失败。
2. **稳态流程维护 ~2.2 min/任务，是常数，与任务规模无关**。对小任务（T1，本质
   工作 <1.5 min）占比 >60%；对中任务（T3，本质工作 ~2-3 min）占比 ~45%。
   流程税随任务变小而比例放大——直接支持提案的「按任务规模自适应流程」方向。
3. **稳态命令时间中 gate close（10.5 s）+ ledger ×3（8.8 s）占 60%**，且对
   docs-only 变更是纯冗余（F6/F9）；仪式写作（plan-evidence-input）是稳态单项
   最大项，但模板复用可将其压到 ~1.5 min（F10），首跑无模板时是主要成本之一。
4. **质量维度未观察到 Harness 优势的直接证据**（两组验收全过、零缺陷）；其价值
   目前体现在可重复性、审计轨迹与知识候选——这些是原生组不产出的资产。
